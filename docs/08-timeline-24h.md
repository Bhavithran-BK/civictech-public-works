# 08 - 24-Hour Timeline

| Hours | Goal |
|---|---|
| 0-2 | Idea lock, schema, OpenAPI, mock data, repo and CI, empty deploys live |
| 2-8 | **A:** map + detail. **B:** login + project form. **C:** CRUD + auth. **D:** seed data + image upload |
| 8-14 | Conflict engine, check-in flow, health score, first real frontend-to-API integration |
| 14-18 | Dashboard, notifications, QR, edge cases. **Feature freeze at hour 18** |
| 18-21 | Bug bash on the deployed link, mobile testing, performance, README |
| 21-23 | Record the demo video (D leads, everyone reviews). Redeploy a clean build |
| 23-24 | Buffer. Do not touch the code unless something is broken |

## Sleep
After hour 12, sleep in shifts of 2 people at a time, about 2 hours each. Never have the whole team asleep or the whole team exhausted at hour 20.

## Checkpoints
- **Hour 2:** contracts agreed, deploys live (even if empty).
- **Hour 8:** frontend talking to the real API.
- **Hour 14:** demo flow works end to end, even if ugly.
- **Hour 18:** feature freeze.
- **Hour 21:** video recording starts.

## If you fall behind
Cut in this order: nice-to-haves, email subscriptions, QR styling, dashboard savings estimate. **Never cut:** map, project page, conflict engine, citizen report, deployment.
